Scope Studio / verified local architecture

A shared signal-processing framework for terminal scopes.

Audio and network applications provide different sources and renderers. The local scope-core crate owns the generic event loop, configuration, shared series model, and terminal rendering pipeline.

Whole framework

Two application crates plug source-specific capture and processing into a generic local runtime. Frames become shared Series, then draw_frame() dispatches to the selected terminal visualization.

Dependency boundary

Direct: audio-scope and net-scope depend on local ../scope-core.

What is reusable

scope-core is the framework boundary: implement DataSource and Renderer, then reuse pacing, input handling, configuration, terminal lifecycle, shared series, and visual dispatch.

What “uses Scope-TUI” means here

The repository keeps an upstream Scope-TUI remote as a reference, but the running applications use this workspace’s local crates. Spectrum and spectrogram DSP/rendering were added locally rather than imported from upstream’s Spectroscope module.
